Build a modern, premium-quality full-stack web application called **“Books In Budget”** for a real bookstore business. The app should look and feel like a modern animated ecommerce platform with smooth UI, responsive layouts, elegant transitions, and production-level architecture.

The application must be built using the following stack:

## Tech Stack

### Frontend

* React.js + Vite
* Tailwind CSS
* React Router DOM
* Framer Motion
* Axios
* Lucide React Icons
* TanStack React Query
* Context API for Cart and Wishlist
* Responsive mobile-first design

### Backend

* Spring Boot 3
* Java 21
* Spring Web
* Spring Data JPA
* MySQL
* Maven
* REST APIs
* Global Exception Handling
* DTO Pattern
* CORS Configuration

### Database

* MySQL

---

# Main Goal

Create a premium bookstore web application similar to modern ecommerce websites like Amazon Books or premium indie bookstores, but focused on:

* Affordable books
* Budget-based discovery
* Modern UI/UX
* Smooth animations
* Elegant typography
* Fast performance

The design should feel:

* Minimal
* Modern
* Dynamic
* Interactive
* Premium
* Smoothly animated

Use subtle gradients, hover effects, glassmorphism, smooth scrolling, animated sections, skeleton loading, and responsive grids.

# Backend Requirements

## REST API Endpoints

### Books APIs

* GET /api/books
* GET /api/books/{id}
* POST /api/books
* PUT /api/books/{id}
* DELETE /api/books/{id}

### Special APIs

* GET /api/books/trending
* GET /api/books/featured
* GET /api/books/budget?maxPrice=199
* GET /api/books/categories
